Acerca de Mi

Hola me llamo Jose Miguel Perez, soy desarrollador web con experiencia en múltiples tecnologías, incluyendo HTML, CSS, JavaScript, TypeScript y frameworks como Angular. En el backend, manejo Java con Spring Boot, Node.js con Express y bases de datos como MySQL y MongoDB. Trabajo con metodologías ágiles, control de versiones con Git y despliegue en plataformas como Firebase. Me apasiona crear interfaces modernas, accesibles y optimizadas para todos los dispositivos. Estoy en constante aprendizaje y disfruto colaborar en proyectos que integren diseño y funcionalidad. Mi objetivo es desarrollar soluciones web eficientes que aporten valor real a usuarios y clientes.
